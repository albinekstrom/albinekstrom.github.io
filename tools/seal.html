Seal the link list

Everything here happens in this browser. The passphrase is never sent anywhere, never written to the repo and never stored — only what it encrypts is. Choose a passphrase you will still remember in February, because there is no reset: if you lose it, reseal with a new one from this page.

Save it as data/links.enc in this repo, commit, push. Then open the site, enter the passphrase, and check the red placeholder warning is gone.
