Seal the link list

Everything happens in this file. The passphrase is never sent anywhere, never written to the repo and never stored — only what it encrypts is. Choose one you will still remember in February: there is no reset, only resealing with a new one from this page.

This page is allowed to make no network requests at all. Open it from disk with the wifi off if you like — it will work exactly the same.

Save it as data/links.enc in this repo, commit and push. Then open the site, enter the new passphrase, and check the red placeholder warning is gone.
